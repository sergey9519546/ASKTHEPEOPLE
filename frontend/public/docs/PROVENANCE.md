# Project provenance and lineage

ASKTHEPEOPLE is an adaptation of [MiroFish](https://github.com/666ghj/MiroFish),
created by 666ghj and its contributors. It is not an independently created
codebase.

The shared repository history begins with MiroFish commit
`38e3d05b1d33d13fcbadc83ec0c4bf84c878e828`. Substantial parts of the backend,
frontend, prompts, simulation workflow, documentation history, and original
assets descend from MiroFish. Later commits adapt, extend, rebrand, test, and
operate the system as ASKTHEPEOPLE.

The social-media-like simulation environments use
[OASIS](https://github.com/camel-ai/oasis), developed by CAMEL-AI contributors.
OASIS supplies simulation mechanics; its use does not establish external
validity for an ASKTHEPEOPLE scenario.

ASKTHEPEOPLE intentionally does not inherit prediction, high-fidelity,
precise-trajectory, or digital-world marketing claims. Its product boundary is
synthetic scenario exploration and pretesting. Generated outputs are not human
evidence, public opinion, or forecasts.

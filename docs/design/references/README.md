# Governed design references

This directory contains repository-owned visual references used to review
implementation fidelity. A reference image expresses visual direction. It does
not override the Product Truth Contract, security policy, architecture ADRs,
content system, or accessibility requirements.

The reference establishes the following transferable visual rules:

- carbon ground, warm cream paper, signal red, and restrained yellow accents;
- oversized compressed typography used as architecture;
- hard rules, square geometry, and a single dominant crop;
- one red route-selection gesture with equal-weight alternative paths;
- no probability, popularity, confidence, or public-opinion encoding.

It does not authorize courtroom, governmental, or public-authority language;
live-run intervention; fabricated path data; or client-generated provenance.

The v2 pack keeps five non-negotiable compositional characteristics:

1. the monumental masthead and decision question share the opening field;
2. the numbered black spine establishes sequence and remains visually severe;
3. the grayscale architectural crop and curved chamber form create one
   sculptural working arena rather than decorative background imagery;
4. the right column marks a context or research threshold, not a public body;
5. the bottom record makes chronology visible without exposing raw logs.

Rasterized example copy is illustrative. Production implementation MUST use
the repository content system and canonical server data. In particular, it
MUST use `Run Record`, MUST NOT imply a public institution, MUST NOT fabricate
owners or dates, and MUST NOT interpret red, layout, or path position as
probability, confidence, public support, or recommendation.

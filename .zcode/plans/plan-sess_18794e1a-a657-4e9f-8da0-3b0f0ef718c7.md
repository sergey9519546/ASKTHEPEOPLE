# Immediate Fix: Repair Broken Frontend Upload Flow

## Problem Summary
The frontend collects files in Home.vue but never uploads them to the backend. Process.vue navigates without calling the ontology generation API, causing the entire flow to break.

## Solution: 3-File Fix

### File 1: `frontend/src/views/Process.vue`
**Changes needed:**
1. Import `generateOntology` from `../api/graph`
2. Import `getPendingUpload, clearPendingUpload` from `../store/pendingUpload.js`
3. Add `uploadAndGenerateOntology()` function to consume pending files
4. Add `pollOntologyTask()` function to wait for ontology completion
5. Update `initProject()` to check for pending upload and handle different project states
6. Add `ontologyPollTimer` cleanup in `onUnmounted`

**Key logic:**
```javascript
// Check if we have pending files from Home.vue
const pending = getPendingUpload();
if (pending.isPending && currentProjectId === 'new') {
  // Build FormData and POST to /api/graph/ontology/generate
  await uploadAndGenerateOntology(pending);
  // Poll task status until ontology is ready
  // Then start graph build
}
```

### File 3: `frontend/src/store/pendingUpload.js` (already correct)

## Implementation Steps

1. **Update Process.vue imports** (line 119)
   - Add `generateOntology` to the import from `../api/graph`
   - Add `getPendingUpload, clearPendingUpload` imports

2. **Add upload handler** (after line 168)
   - Create `uploadAndGenerateOntology(pending)` function
   - Build FormData with files and form fields
   - Call `generateOntology(formData)`
   - Handle success/error
   - Update router with actual project_id

3. **Add ontology polling** (after upload handler)
   - Create `pollOntologyTask(taskId)` function
   - Poll every 2s checking task status
   - Update progress indicator (0-50% for ontology)
   - On completion, load project data and trigger graph build
   - On failure, show error

4. **Refactor initProject()** (line 169-175)
   - Check `getPendingUpload()` first
   - If pending and projectId === 'new', call upload handler
   - Otherwise load existing project
   - Handle different project states: CREATED, ONTOLOGY_GENERATED, GRAPH_BUILDING, GRAPH_COMPLETED

5. **Update cleanup** (line 220)
   - Add `ontologyPollTimer` variable declaration
   - Clear both timers in `onUnmounted`

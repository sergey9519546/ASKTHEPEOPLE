## 2024-05-28 - Vue List Rendering with v-memo\n**Learning:** In Vue 3, `v-memo` is a highly effective way to prevent unnecessary re-renders in large lists, especially those that depend on local UI states like `hoveringCard`. It drastically reduces VNode creation when dependencies (like primitive ids and booleans) remain unchanged.\n**Action:** Use `v-memo` for large lists and ensure dependency arrays use primitive properties because Vue uses strict equality for change detection.
